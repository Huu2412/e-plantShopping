# Paradise Nursery Shopping Application

An online plant shopping cart web application built with React and Redux Toolkit.

## Overview
Paradise Nursery is a dynamic e-commerce web application that allows users to browse a diverse collection of houseplants, view detailed plant information (including images, names, descriptions, and prices), add plants to their shopping cart, and seamlessly manage cart items.

## Key Features
- **Landing Page:** Engaging welcome screen with company background and quick "Get Started" access.
- **Product Catalog:** Houseplants categorized into multiple groups (Air Purifying, Aromatic Fragrant, Insect Repellent, Medicinal, and Low Maintenance Plants) with responsive card layouts and dynamic "Add to Cart" functionality.
- **Shopping Cart Management:** Centralized Redux state management enabling item addition, removal, quantity adjustments, item cost calculation, and total cart value updates.
- **Responsive Navigation:** Interactive navigation bar featuring real-time cart item count indicators.

## Tech Stack
- React 18
- Redux Toolkit & React-Redux
- Vite
- CSS3
